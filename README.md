## ملف البيانات (`data/places.xlsx`)

يعبّئه موظف واحد مسؤول عن البيانات. فيه خمس أوراق وورقة تعليمات:

| الورقة | ماذا فيها | الإحداثيات؟ |
|---|---|---|
| **المباني** | حرف المبنى (A, B, E…)، اسمه، الكليات والدوائر فيه، هل فيه مصعد | لا |
| **المداخل** | لكل مبنى مدخل أو أكثر (رئيسي/فرعي) مع وصف جهته | **نعم**، لكل مدخل |
| **البوابات** | بوابات الجامعة الثلاث | **نعم** |
| **الأشخاص** | المحاضرون والموظفون: الاسم، اللقب، الفئة (محاضر/موظف)، **الصفة الوظيفية** (عميد الكلية، رئيس القسم، سكرتير…)، الكلية، القسم، **رقم المكتب**، الساعات المكتبية | لا |
| **الأماكن** | القاعات والمختبرات والمشاغل والدوائر والوحدات والكافتيريا والحمامات… مع **رقم الغرفة** والكلية المالكة | للأماكن الخارجية فقط (مواقف، ملاعب) |

**الصفة الوظيفية:** اختر من القائمة أو اكتب غيرها. كلمات «الكلية» و«القسم» و«الدائرة» تُستبدل تلقائياً بالاسم من نفس الصف، فتصبح «عميد الكلية» مثلاً «عميد كلية الهندسة والتكنولوجيا». ويستطيع الطالب البحث بها: «وين عميد كلية الهندسة؟» أو «سكرتير قسم …».

**رقم الغرفة هو أساس العنونة:** `E213` تعني المبنى E، الطابق 2 (الأرضي = 0). ويمكن أن ينتهي الرقم بحرف صغير، مثل `E330b` أو `A120g`. يكفي كتابة رقم الغرفة، فيستنتج البوت المبنى والطابق. للأماكن التي ليس لها رقم (مثل الكافتيريا) اكتب حرف المبنى والطابق.

**الإحداثيات مطلوبة لمداخل المباني والبوابات فقط**، أي حوالي 20 نقطة تكفيها جولة واحدة في الحرم. قف عند باب كل مدخل، واضغط مطولاً على نقطتك الزرقاء في Google Maps، ثم انسخ الرقمين: الأول خط العرض، والثاني خط الطول.

قواعد:
- الأعمدة الحمراء إجبارية، ومرّر الفأرة فوق أي عنوان لترى شرحه.
- لا تغيّر أسماء الأوراق ولا عناوين الأعمدة.
- الصفوف الصفراء أمثلة، وفي اسمها كلمة «مثال»، والبوت يتجاهلها.
- الملاحظات التي تبدأ بـ «داخلي» أو فيها «تحقق» أو «أكمل» لا تظهر للطلاب.
- الأسماء البديلة تُفصل بفاصلة، مثل: كافتيريا، مطعم، قهوة.

افحص الملف على جهازك قبل رفعه:
```bash
python check_data.py data/places.xlsx
```

### الفحص التلقائي: البيانات لا تتلف أبداً
عند رفع الملف يرفضه البوت كاملاً إذا وجد فيه خطأ، ويبقى على النسخة السابقة، ويرسل لك الأخطاء باسم الورقة ورقم الصف. أمثلة على الأخطاء:
- رقم غرفة بصيغة خاطئة، مثل `E2O4` بحرف O بدل الصفر.
- مبنى غير موجود في ورقة المباني، أو حرف مبنى مكرر.
- صفة غير «محاضر» أو «موظف»، أو نوع مكان غير موجود في القائمة.
- إحداثيات مقلوبة (خط العرض مكان خط الطول).
- ملف ناقص فيه أقل من نصف السجلات الحالية.

قبل كل استبدال تُحفظ نسخة احتياطية في `data/backups/`.

### الرفع والتحديث عبر تلجرام
ضع رقم حسابك في `ADMIN_IDS` في `.env`، ثم من محادثتك **الخاصة** مع البوت:

| ماذا تريد؟ | ماذا ترسل للبوت؟ |
|---|---|
| رفع أو استبدال البيانات | ملف `places.xlsx` كمستند |
| تعديل البيانات الحالية | `/export` فيرسل لك الملف الحالي، عدّله ثم أعد إرساله |
| صورة مدخل مبنى | الصورة مع حرف المبنى في التعليق، مثل `E` |
| صور كل المباني مرة واحدة | ملف `zip` فيه `A.jpg` و`B.jpg` و`E.jpg`… |
| تقرير عن النواقص | `/check` |
| حذف سجلات كثيرة عن قصد | أرسل الملف واكتب في تعليقه: `تأكيد` |

## الموقع والاتجاهات

- **زر «📍 أرسل موقعي»** ظاهر دائماً أسفل المحادثة. بعد أن يضغطه الطالب، يحسب البوت المسافة والاتجاه ويعطيه رابط Google Maps للمشي من مكانه.
- **أقرب مدخل:** المبنى الذي له مدخلان يوجَّه الطالب إلى المدخل الأقرب منه.
- **من خارج الجامعة:** إذا كان الطالب أبعد من 250 متراً عن الحرم، يختار البوت البوابة الأنسب (الشمالية الرئيسية، أو الجنوبية، أو بوابة مبنى الطاقة)، ويمر بها رابط الطريق.
- **الموقع المباشر:** إذا شارك الطالب موقعه المباشر، يرسل له البوت «قربت!» ثم «🎉 وصلت إلى المدخل… توجّه إلى الطابق الثاني، المكتب E204».
- **المصاعد:** للطوابق العليا يذكر البوت إن كان في المبنى مصعد، أو ينبّه إلى أن الصعود بالدرج (المباني A وD وL وS).
- **«وين أقرب حمام؟»** يستخدم موقع الطالب، أو المبنى الذي يذكره («أنا في مبنى H، وين أقرب حمام؟»).

### خريطة الجامعة التفاعلية
```bash
python make_map.py
```
يُنشئ مجلد `campus_map/`، فيه خريطة بمداخل المباني والبوابات، وبحث بالأسماء وأرقام الغرف يفتح المبنى المطلوب. ارفعه على موقع الجامعة أو على Netlify مجاناً. ولوضع خريطة الجامعة المرسومة فوقها:
```bash
python make_map.py --overlay uni_map.png --bounds <جنوب>,<غرب>,<شمال>,<شرق>
```

## تطبيق الويب (يُثبَّت على الهاتف)

نسخة من الدليل تعمل في متصفح الهاتف، ويثبّتها الطالب على الشاشة الرئيسية فتظهر كتطبيق بأيقونة. تعمل على أندرويد وآيفون، ولا تحتاج متجراً ولا ذكاءً اصطناعياً ولا خادماً:
- **نفس البحث ونفس الردود:** البحث نفسه الذي يستخدمه البوت بدون Gemini، منقول كما هو إلى داخل الهاتف.
- **قائمة الخيارات:** الأسماء المتشابهة تظهر قائمة مرقمة يضغط الطالب على أحدها.
- **الموقع تلقائياً:** يحدَّد بالـ GPS، ثم يُحسب أقرب مدخل والبوابة المناسبة ورابط Google Maps.
- **التنبيه عند الوصول:** يصل الطالب تنبيه «قربت!» ثم «وصلت» عند المدخل، مع الطابق ورقم الغرفة.
- **يعمل بدون إنترنت** بعد أول فتح، عدا خريطة الشوارع.
- **تحديث البيانات:** في كل مرة يفتح الطالب التطبيق ومعه إنترنت، يجلب آخر نسخة من البيانات.

### من أين تأتي البيانات؟
من نفس ملف الإكسل. في كل مرة يقبل البوت الملف (عند التشغيل، أو بعد `/reload`، أو بعد رفع ملف أو صورة)، يكتب نسخة منه في `web/data.json` ويحدّث الصور في `web/photos/`. الملاحظات الداخلية (التي فيها «داخلي» أو «تحقق»…) لا تُنشر.

### النشر مجاناً على GitHub Pages (مرة واحدة، حوالي 10 دقائق)
1. أنشئ حساباً مجانياً على github.com، ثم أنشئ مستودعاً جديداً **Public** باسم مثل `campus-guide`.
2. في صفحة المستودع اضغط **Add file ← Upload files**، واسحب **محتويات** مجلد `web` (وليس المجلد نفسه)، ثم **Commit changes**.
3. افتح **Settings ← Pages**. تحت Source اختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة أو دقيقتين يصبح التطبيق على الرابط `https://اسم_حسابك.github.io/campus-guide/`.

### التحديث التلقائي (حتى لا ترفع الملفات بنفسك كل مرة)
1. افتح github.com/settings/personal-access-tokens، واضغط **Generate new token** (من نوع Fine-grained).
2. تحت **Repository access** اختر **Only select repositories** ثم المستودع. تحت **Permissions ← Contents** اختر **Read and write**.
3. أضف السطور التالية إلى `.env` ثم أعد تشغيل البوت:
```
GITHUB_REPO=اسم_حسابك/campus-guide
GITHUB_TOKEN=github_pat_****
```
بعدها يرد البوت بعد كل رفع لملف الإكسل بسطر مثل «🌐 تطبيق الويب: تم نشر 1 ملف»، وتصل البيانات الجديدة للطلاب خلال دقيقة أو دقيقتين. لا تُرسل `GITHUB_TOKEN` في أي محادثة أو صورة شاشة، فهو مثل كلمة السر.

يمكنك تجربة النشر يدوياً بالأمر `python web_publish.py`.

### تثبيته على الهاتف
- **أندرويد (Chrome):** افتح الرابط، ثم اضغط زر «⬇️ تثبيت» في أعلى التطبيق، أو من قائمة ⋮ اختر «تثبيت التطبيق».
- **آيفون (Safari):** افتح الرابط، ثم اضغط زر المشاركة ⬆️، ثم «إضافة إلى الشاشة الرئيسية».

يمكن نشر الرابط برمز QR على أبواب المباني، أو في مجموعات الطلبة.

### التجربة على جهازك قبل النشر
```bash
cd web
python -m http.server 8000
```
ثم افتح `http://localhost:8000` في المتصفح. لن يعمل تحديد الموقع على هاتف آخر إلا بعد النشر على رابط https.

## أوامر البوت
للجميع:
- `/start`: رسالة الترحيب.
- `/new`: بدء محادثة جديدة ومسح السياق (يعمل أيضاً في محادثات حساب الجامعة).

للمشرفين فقط:
- `/check`: فحص الملف الحالي ونواقصه.
- `/export`: تنزيل ملف الإكسل الحالي.
- `/reload`: إعادة قراءة المصدر (Google Sheets أو الملف على السيرفر).

## التشغيل الدائم (24/7)
جهازك الشخصي يصلح للتجربة فقط. عند الإطلاق الفعلي اختر أحد الخيارات التالية:
- **Railway** أو **Render**: ارفع المجلد على GitHub، ثم أنشئ خدمة من نوع *Background Worker* بأمر التشغيل `python bot.py`، وأضف متغيرات `.env` في إعدادات الخدمة.
- **سيرفر الجامعة** أو **VPS** لينكس: شغّل البوت كخدمة `systemd` حتى يعود تلقائياً بعد أي إعادة تشغيل.

## التكلفة التقريبية
- تلجرام: البوت مجاني. وضع حساب الجامعة (Telegram Business) قد يتطلب اشتراك Premium للحساب.
- الذكاء الاصطناعي: **مجاني** مع Gemini أو Groq ضمن حدود الاستخدام المجاني، أو بدون ذكاء اصطناعي إطلاقاً (`none`).
- عند التوسع لكل طلاب الجامعة قد تحتاج الجامعة خطة مدفوعة (Gemini أو Claude)، وتكلفتها حسب الاستخدام.
- الاستضافة: جهازك للتجربة مجاناً. للتشغيل الدائم تتوفر خطط مجانية محدودة عند بعض المزوّدين، أو سيرفر الجامعة.

## ملاحظات
- البوت لا يخترع أماكن. إذا لم يجد المكان في الجدول، يحيل الطالب إلى الجهة المذكورة في `CONTACT_FALLBACK`.
- خذ موافقة المحاضرين قبل نشر مواقع مكاتبهم وساعاتهم المكتبية.
- ذاكرة المحادثات مؤقتة، تُحفظ في الذاكرة وتُمسح عند إعادة تشغيل البوت.
- عند الاستضافة على Render أو Railway، اربط مجلدي `data/` و`photos/` بقرص دائم (Persistent Disk / Volume)، وإلا ستُمسح الصور والبيانات المرفوعة عند كل تحديث للسيرفر.
- الخطوة التالية: إضافة جدول المحاضرات حتى يجيب البوت عن سؤال مثل "وين محاضرتي الساعة 10؟"، ثم نقل البوت نفسه إلى واتساب.
