## ملف البيانات (`data/places.xlsx`)

يعبّئه موظف واحد مسؤول عن البيانات. فيه خمس أوراق وورقة تعليمات:

| الورقة | ماذا فيها | الإحداثيات؟ |
|---|---|---|
| **المباني** | حرف المبنى (A, B, E…)، اسمه، الكليات والدوائر فيه، هل فيه مصعد | لا |
| **المداخل** | لكل مبنى مدخل أو أكثر (رئيسي/فرعي) مع وصف جهته | **نعم**، لكل مدخل |
| **البوابات** | بوابات الجامعة الثلاث | **نعم** |
| **الأشخاص** | المحاضرون والموظفون: الاسم، اللقب، الفئة (محاضر/موظف)، **الصفة الوظيفية** (عميد الكلية، رئيس القسم، سكرتير…)، الكلية، القسم، **رقم المكتب**، الساعات المكتبية | لا |
| **الأماكن** | القاعات والمختبرات والمشاغل والدوائر والوحدات والكافتيريا والحمامات… مع **رقم الغرفة** والكلية المالكة | للأماكن الخارجية فقط (مواقف، ملاعب) |

**الصفة الوظيفية:** اختر من القائمة أو اكتب غيرها. كلمات «الكلية» و«القسم» و«الدائرة» تُستبدل تلقائياً بالاسم من نفس الصف، فتصبح «عميد الكلية» مثلاً «عميد كلية الهندسة والتكنولوجيا». ويستطيع الطالب البحث بها: «وين عميد كلية الهندسة؟» أو «سكرتير قسم …».

**رقم الغرفة هو أساس العنونة:** `E213` تعني المبنى E، الطابق 2 (الأرضي = 0). ويمكن أن ينتهي الرقم بحرف صغير، مثل `E330b` أو `A120g`. يكفي كتابة رقم الغرفة، فيستنتج البوت المبنى والطابق. للأماكن التي ليس لها رقم (مثل الكافتيريا) اكتب حرف المبنى والطابق.

**الإحداثيات مطلوبة لمداخل المباني والبوابات فقط**، أي حوالي 20 نقطة تكفيها جولة واحدة في الحرم. قف عند باب كل مدخل، واضغط مطولاً على نقطتك الزرقاء في Google Maps، ثم انسخ الرقمين: الأول خط العرض، والثاني خط الطول.

قواعد:
- الأعمدة الحمراء إجبارية، ومرّر الفأرة فوق أي عنوان لترى شرحه.
- لا تغيّر أسماء الأوراق ولا عناوين الأعمدة.
- الصفوف الصفراء أمثلة، وفي اسمها كلمة «مثال»، والبوت يتجاهلها.
- الملاحظات التي تبدأ بـ «داخلي» أو فيها «تحقق» أو «أكمل» لا تظهر للطلاب.
- الأسماء البديلة تُفصل بفاصلة، مثل: كافتيريا، مطعم، قهوة.

افحص الملف على جهازك قبل رفعه:
```bash
python check_data.py data/places.xlsx
```

### الفحص التلقائي: البيانات لا تتلف أبداً
عند رفع الملف يرفضه البوت كاملاً إذا وجد فيه خطأ، ويبقى على النسخة السابقة، ويرسل لك الأخطاء باسم الورقة ورقم الصف. أمثلة على الأخطاء:
- رقم غرفة بصيغة خاطئة، مثل `E2O4` بحرف O بدل الصفر.
- مبنى غير موجود في ورقة المباني، أو حرف مبنى مكرر.
- صفة غير «محاضر» أو «موظف»، أو نوع مكان غير موجود في القائمة.
- إحداثيات مقلوبة (خط العرض مكان خط الطول).
- ملف ناقص فيه أقل من نصف السجلات الحالية.

## ملاحظات
- البوت لا يخترع أماكن. إذا لم يجد المكان في الجدول، يحيل الطالب إلى الجهة المذكورة في `CONTACT_FALLBACK`.
- خذ موافقة المحاضرين قبل نشر مواقع مكاتبهم وساعاتهم المكتبية.
- ذاكرة المحادثات مؤقتة، تُحفظ في الذاكرة وتُمسح عند إعادة تشغيل البوت.
- عند الاستضافة على Render أو Railway، اربط مجلدي `data/` و`photos/` بقرص دائم (Persistent Disk / Volume)، وإلا ستُمسح الصور والبيانات المرفوعة عند كل تحديث للسيرفر.
- الخطوة التالية: إضافة جدول المحاضرات حتى يجيب البوت عن سؤال مثل "وين محاضرتي الساعة 10؟"، ثم نقل البوت نفسه إلى واتساب.
